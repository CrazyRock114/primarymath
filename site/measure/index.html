图形的测量
不会的，切；切不动的，补；立体的，展开

这一批的核心

公式不是要背的清单，是「化归」这条主线上的结果。

组合图形 → 切或补 → 变成学过的平面图形
梯形 → 剪一刀 → 拼成平行四边形的一半（所以 ÷2）
立体图形 → 展开 → 变回平面图形

三个动作（切 / 补 / 展开）其实是同一个动作：把不会的变成会的。
学会这一个，几何题就不再需要「多背公式」了。

本批两节
  1. ① 组合图形的面积 —— 切不动就补（五上 多边形的面积 + 三上 测量）
  2. ② 立体：表面积与体积 —— 展开图解决一切（五下 长方体正方体 + 六下 圆柱圆锥）

1与已完成内容的连接

本批是形柱「割补转化」的全面展开：

  1. 形柱　割补转化是什么（已建：平行四边形剪拼成矩形图示）
  2. 本批 ①　平面怎么切、怎么补——组合图形与梯形
  3. 本批 ②　立体怎么展开——表面积与体积
  4. 支柱二「量」　面积的原始定义是数格子——公式只是快捷方式

「数格子 → 公式 → 化归」是同一套方法的三级台阶：
不会数 → 记住公式 → 公式也不会时，回到数格子。 孩子有了这条兜底路径，再难的图形也不会「卡住不动」。

家长可以先做的判断

孩子几何计算卡住，先问这三句：

「能不能切一刀？切不动就补一块？」
「这个公式里的 ÷2 / 2 个底面，我为什么要它？」
「立体能展开成什么平面图形？」

三句都能答上，几何计算就不会差。答不上来的那句，就是他真正的卡点。
