01孩子说「下一个是 6」，他真的懂了吗

先看痛点

题目：1, 2, 3, 4, 5, ___
孩子答「6」，对。但这可能只是因为 1~5 他背过。
换成 1, 3, 5, 7, ___ 他也答「9」——这个才是真找到规律了。
再换成 1, 2, 3, 4, ___ 后面接图形，他就完全不会了。

再纠一个偏

找到规律 = 找到「这个数是怎么来的」，不是记住「下一个是什么」。

1, 2, 3, 4, 5 的规律不是「下一个是 6」，
规律是「每一个都比前一个多 1」。

这个区别很实际：
· 只会「下一个是 6」→ 换个起点就废（11, 12, 13, 14, __ 呢？）
· 懂「每次 +1」→ 任何起点、任何长度都能推

动手试：找出那个「动作」

拖动改变「每次加几」。看第 7 个之后能不能无限推下去。

02溯源：找规律是人类的「预测本能」

回到源头

为什么要让孩子学找规律？因为数学的定义就是「从已知推出未知」。

你知道 1、2、3、4、5，就能预测 6、7、8——
这个「从已知推出未知」的能力，比任何具体知识都重要。

所以找规律不是一种题型，是一个思维习惯：
看到一串东西，先问「它是怎么来的」，而不是「下一个是什么」。

03图形规律和数列规律

图形规律

看形状怎么变：
· ○△○△ → 动作是「交替」
· ○○△○○△ → 动作是「两个一换」
· ○○△△○○△△ → 动作是「两个一换」

孩子最容易错：○○△ 和 ○○△△ 看成同一种。
前者动作是「1 换 1」，后者是「2 换 2」——动作不同，延续不同。

数列规律

看数怎么变：
· 1,2,3,4 → 每次 +1
· 1,3,5,7 → 每次 +2
· 1,2,4,8 → 每次 ×2
· 1,1,2,3,5,8 → 每次 =前两个之和

「怎么来的」比「是什么」重要——1,2,4,8 的动作是「每次翻倍」，2,4,8,16 也是。

今晚就能用的一句话

「这个数是怎么来的？」

孩子答完「下一个是几」之后，一定要追这一句。 答「加 1」而不是「加 1、2、3、4 加到 5」——这才是真找到规律了。
